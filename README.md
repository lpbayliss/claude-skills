# claude-skills

A curated collection of Claude Code skills, plugins, hooks, and utilities — the tools I reach for regularly, gathered in one marketplace.

Where a well-regarded upstream maintainer publishes a skill or plugin, this marketplace references it directly so it stays current. Skills I author myself live in this repo.

## Install

```
/plugin marketplace add lpbayliss/claude-skills
```

Then browse and install individual plugins with `/plugin`.
